MEDIDAS DAX PROPUESTAS - COLORES KPI FRAUS
============================================

Usar [color_kpi_fraus_switch] en Formato condicional > Color de fondo
(o Color de fuente) > Formatear por: Valor de campo.

Las cuatro medidas de escala son los valores a partir de los que se
considera que el KPI ha alcanzado su intensidad maxima. Ajustarlas con
los umbrales que acuerde negocio.

measure escala_color_fraus_m3 = 100000

measure escala_color_fraus_import = 100000

measure escala_color_fraus_recuperats = 100

measure escala_color_fraus_detectats = 100


measure color_kpi_fraus_switch =
    VAR _Kpi =
        SELECTEDVALUE ( '_parameter_fraus'[Parámetro] )

    VAR _Valor =
        SWITCH (
            _Kpi,
            "Fraus Detectats", [kpi_fraus_detectats_switch],
            "Fraus Recuperat (m3)", [kpi_fraus_m3_switch],
            "Fraus Total Import", [kpi_fraus_total_import_switch],
            "Fraus Recuperats", [kpi_fraus_recuperats_switch],
            "% Fraus Recuperacio", [kpi_pct_fraudes_recupera_switch],
            BLANK ()
        )

    VAR _Escala =
        SWITCH (
            _Kpi,
            "Fraus Detectats", [escala_color_fraus_detectats],
            "Fraus Recuperat (m3)", [escala_color_fraus_m3],
            "Fraus Total Import", [escala_color_fraus_import],
            "Fraus Recuperats", [escala_color_fraus_recuperats],
            "% Fraus Recuperacio", 1,
            BLANK ()
        )

    VAR _Nivel =
        MIN ( 1, MAX ( 0, DIVIDE ( _Valor, _Escala, 0 ) ) )

    RETURN
        SWITCH (
            TRUE (),
            ISBLANK ( _Kpi ) || ISBLANK ( _Valor ), BLANK (),

            // Fraus detectats: mes casos implica peor resultado.
            _Kpi = "Fraus Detectats" && _Nivel = 0, "#FFFFFF",
            _Kpi = "Fraus Detectats" && _Nivel <= 0.25, "#E2F0D9",
            _Kpi = "Fraus Detectats" && _Nivel <= 0.50, "#A9D18E",
            _Kpi = "Fraus Detectats" && _Nivel <= 0.75, "#F4B183",
            _Kpi = "Fraus Detectats", "#C00000",

            // Volumen recuperado e importe: mas recuperacion, verde mas oscuro.
            _Kpi IN { "Fraus Recuperat (m3)", "Fraus Total Import" } && _Nivel = 0, "#FFFFFF",
            _Kpi IN { "Fraus Recuperat (m3)", "Fraus Total Import" } && _Nivel <= 0.25, "#E2F0D9",
            _Kpi IN { "Fraus Recuperat (m3)", "Fraus Total Import" } && _Nivel <= 0.50, "#A9D18E",
            _Kpi IN { "Fraus Recuperat (m3)", "Fraus Total Import" } && _Nivel <= 0.75, "#70AD47",
            _Kpi IN { "Fraus Recuperat (m3)", "Fraus Total Import" }, "#548235",

            // Fraus recuperats: cero recuperaciones es rojo; mas recuperaciones, verde mas oscuro.
            _Kpi = "Fraus Recuperats" && _Nivel = 0, "#C00000",
            _Kpi = "Fraus Recuperats" && _Nivel <= 0.25, "#F4B183",
            _Kpi = "Fraus Recuperats" && _Nivel <= 0.50, "#FFD966",
            _Kpi = "Fraus Recuperats" && _Nivel <= 0.75, "#A9D18E",
            _Kpi = "Fraus Recuperats", "#548235",

            // Porcentaje de recuperacion: de rojo (0 %) a verde oscuro (100 %).
            _Kpi = "% Fraus Recuperacio" && _Nivel <= 0.25, "#C00000",
            _Kpi = "% Fraus Recuperacio" && _Nivel <= 0.50, "#F4B183",
            _Kpi = "% Fraus Recuperacio" && _Nivel <= 0.75, "#A9D18E",
            _Kpi = "% Fraus Recuperacio", "#548235",

            BLANK ()
        )


OPCIONAL: COLOR DE FUENTE
-------------------------
Si se usa el color como fondo y se quiere mantener contraste, usar esta
medida en Color de fuente.

measure color_fuente_kpi_fraus_switch =
    VAR _ColorFondo = [color_kpi_fraus_switch]
    RETURN
        SWITCH (
            _ColorFondo,
            "#548235", "#FFFFFF",
            "#70AD47", "#FFFFFF",
            "#C00000", "#FFFFFF",
            "#000000"
        )
