{
  "name": "Aforos7642085036297320.geojson",
  "path": "Aforos7642085036297320.geojson",
  "type": "ShapeMap"
}

NOTA IMPORTANTE sobre la geometría:
El geojson de Aforos contiene geometría tipo "MultiLineString" (tramos de tubería),
no "Point". Por tanto en Azure Maps se debe añadir como "Reference Layer" (capa de
referencia tipo shape/polygon-line), igual que se hizo con sectors.geojson, y NO como
"Bubble Layer" (que requiere latitud/longitud de un punto). El campo por el que Azure
Maps hace el join espacial normalmente es OBJECTID (o el campo equivalente que se use
como "Location key"); en dim_pozos ese campo es "Object_id".
