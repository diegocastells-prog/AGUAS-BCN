4) grup_pressio_nit_activo
--------------------------------------------
DAX:
IF (
    SUM ( dim_gerencia_pressio[grup_pressio_nit] ) > 0,
    1,
    BLANK ()
)

formatString: 0
lineageTag: e5085bbe-9e27-4d1c-a381-637df61dc7b3
Descripción: Medida "gate"/condición para el LPI (mapa de sectores). Devuelve 1 cuando la suma de
la columna grup_pressio_nit es mayor que 0, y BLANK() en caso contrario. Pensada para usarse como
filtro a nivel de visual (filtro "no está en blanco") en el mapa/LPI, de forma que solo se muestren
o se pinten los sectores donde grup_pressio_nit > 0, sin tener que duplicar la condición dentro de
cada una de las medidas anteriores.

--------------------------------------------
USO PROPUESTO EN EL LPI / MAPA DE SECTORES
--------------------------------------------
- Añadir "grup_pressio_nit_activo" al panel de filtros del visual (mapa/LPI) y filtrar
  por "no está en blanco" para que el visual solo actúe cuando grup_pressio_nit > 0.
- Añadir "preal_min", "preal_max" y "diff_preal" al tooltip del visual para mostrar
  las 3 métricas simultáneamente al pasar el cursor sobre cada sector.

--------------------------------------------
NOTA
--------------------------------------------
Si en el futuro se prefiere que el filtrado por grup_pressio_nit > 0 esté embebido
directamente dentro de cada medida (en vez de como filtro de visual), se pueden
reescribir preal_min / preal_max / diff_preal envolviéndolas en un IF con la misma
condición de grup_pressio_nit_activo.
